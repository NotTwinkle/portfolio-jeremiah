# Portfolio Website

My personal portfolio website showcasing my work as a web and application developer. Built from scratch to demonstrate my skills in modern web development, UI/UX design, and creating smooth, interactive user experiences.

## What's Inside

This portfolio features a clean, minimalist design focused on showcasing my projects and experience. The site includes:

- **Hero Section** - Animated introduction with smooth scroll indicators
- **About Me** - Background, experience, and tech stack I work with
- **Projects** - Interactive showcase of my work with detailed case studies
- **Contact** - Ways to reach out and connect

## Key Features

The site uses smooth scrolling powered by Lenis, scroll-triggered animations with GSAP, and is fully responsive across all devices. I've put extra attention into the animations and transitions to create a polished, professional feel without being overwhelming.

Each project has its own detailed case study page where I break down the goals, challenges, solutions, and results. The design emphasizes readability and makes it easy to explore my work.

Built with React, Tailwind CSS, and modern web technologies. Everything is optimized for performance and accessibility.
